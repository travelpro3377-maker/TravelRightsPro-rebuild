# TravelRightsPro.com

A Vercel-ready Next.js MVP focused on travel-rights education, lead generation and travel affiliate monetization.

## Fast launch
1. Create a GitHub repository.
2. Upload this folder.
3. Import the repository into Vercel.
4. Add your custom domain `travelrightspro.com`.
5. Add affiliate URLs in Vercel Environment Variables using `.env.example`.
6. Deploy.

## Monetization plan
- Travel-insurance affiliate offers
- Hotel affiliate offers
- Activities/tours affiliate offers
- Later: paid Travel Rights Report
- Later: email lead funnel and automated follow-up

## Important
Do not claim that every traveler is legally entitled to compensation. Rules vary by itinerary, jurisdiction, carrier and circumstances. Replace the placeholder affiliate URLs with your approved partner links and publish complete privacy/terms pages before collecting personal data.
